Configuracion
Configura una vez. En el segundo y tercer dispositivo pega las mismas claves.
1 — API key de Anthropic
Ve a console.anthropic.com > API Keys > Create Key. Se guarda en este navegador.
2 — Google Sheets (sincronizacion)
3 — Google Client ID (para leer Google Docs)
1
Ve a console.cloud.google.com > APIs > Credenciales > Crear > OAuth 2.0
2
Origenes JS autorizados: https://aleivaarcas-a11y.github.io
3
Activa la Google Docs API en Biblioteca. Copia el Client ID y pegalo abajo.
