Configuracion
Configura una vez. En el segundo y tercer dispositivo pega las mismas claves.
1 — API key de Anthropic (asistente IA)
Ve a console.anthropic.com > API Keys > Create Key. Se guarda solo en este navegador.
2 — Google Sheets (sincronizacion entre dispositivos)
1
Ve a sheets.new y crea una hoja llamada Manual Historia Deporte
2
Menu Extensiones > Apps Script. Pega el codigo del archivo apps_script_notas.js. Guarda.
3
Implementar > Nueva implementacion. Aplicacion web. Ejecutar como: Yo. Acceso: Cualquier usuario.
4
Copia la URL y pegala abajo.
3 — Google Client ID (para leer Google Docs)
1
Ve a console.cloud.google.com > APIs y servicios > Credenciales
2
Crear credenciales > ID de cliente OAuth 2.0 > Tipo: Aplicacion web
3
En "Origenes JS autorizados" anadir la URL de tu GitHub Pages: https://tu-usuario.github.io
4
Activa la Google Docs API en "Biblioteca de APIs". Copia el Client ID y pegalo abajo.
